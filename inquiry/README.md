# NREE presubmission inquiry package

This folder contains a lightweight LaTeX version of the presubmission inquiry:

- `NREE_presubmission_inquiry.tex`

It is designed as an Overleaf-ready subproject inside the same GitHub repository. The file reuses:

- `../references.bib`
- `../figures/draft/fig1_spectra_original.png`
- `../figures/generated/fig2_functional_observables_framework.pdf`
- `../figures/generated/fig3_proof_of_concept_performance.pdf`
- `../figures/generated/fig4_trait_anomaly_syndromes.pdf`
- `../figures/generated/fig5_monitoring_roadmap.pdf`

Recommended use:

1. In Overleaf, set `inquiry/NREE_presubmission_inquiry.tex` as the main document if compiling the inquiry PDF.
2. For the actual journal inquiry form or email, use only the first page unless the editor requests supporting material.
3. Keep the optional supporting note and display-item preview as a PDF attachment only if the inquiry system allows it.
