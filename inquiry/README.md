# NREE presubmission inquiry package

This folder contains a lightweight LaTeX version of the presubmission inquiry:

- `NREE_presubmission_inquiry.tex`
- `NREE_proposal_synopsis.tex`
- `NREE_proposal_synopsis.md`

It is designed as an Overleaf-ready subproject inside the same GitHub repository. The file reuses:

- `../references.bib`
- `../figures/draft/fig1_spectra_original.png`
- `../figures/generated/fig2_functional_observables_framework.pdf`
- `../figures/generated/fig3_proof_of_concept_performance.pdf`
- `../figures/generated/fig4_trait_anomaly_syndromes.pdf`
- `../figures/generated/fig5_monitoring_roadmap.pdf`

Recommended use:

1. In Overleaf, set `inquiry/NREE_proposal_synopsis.tex` as the main document if compiling the formal proposal synopsis.
2. Set `inquiry/NREE_presubmission_inquiry.tex` as the main document if compiling the longer inquiry with optional display-item previews.
3. For the actual journal inquiry form or email, keep the text concise unless the editor requests supporting material.
4. Keep the optional supporting note and display-item preview as a PDF attachment only if the inquiry system allows it.
