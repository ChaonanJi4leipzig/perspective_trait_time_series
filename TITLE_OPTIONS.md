# Title positioning

## Current preferred title

**From greenness to function in ecosystem monitoring**

This is the strongest current option for an NREE/TREE-style Perspective because it is broad, ecological and immediately states the conceptual shift. It avoids making a specific data structure the headline contribution.

## Key phrase to retain

**From spectral snapshots to functional ecosystem monitoring**

Use this as a subtitle-like phrase in the abstract, presubmission inquiry and possibly the opening paragraph. It explains the technical pathway without narrowing the paper to a specific data structure.

## Backup titles

1. From spectral snapshots to functional ecosystem monitoring
2. Functional observables for the next generation of ecosystem monitoring
3. Beyond greenness: observing ecosystem function from space
4. From vegetation indices to functional ecosystem observables
5. Continuous functional observables for ecosystem monitoring

## Terms to avoid in the title

- Trait cube
- Trait data cube
- Internal project name
- Pipeline
- Framework for Sentinel-2 and hyperspectral fusion

These terms can appear in the manuscript when technically useful, but they make the headline too narrow for a high-impact Perspective.
