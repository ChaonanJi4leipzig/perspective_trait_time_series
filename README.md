# EcoSpectra trait-cube Perspective

This repository is an Overleaf-ready LaTeX project for the Perspective manuscript:

**Trait data cubes for ecosystem monitoring**

The manuscript is intended as an opening Perspective for the EcoSpectra project. It should not read as a literature review or as a full research article. The current positioning is:

- sparse imaging spectroscopy provides trait anchors;
- dense multispectral archives provide temporal support;
- the target product is an uncertainty-aware trait data cube;
- EcoSpectra enters as an early proof-of-concept, not as a final benchmark.

## Main files

- `main.tex` - rewritten Perspective draft.
- `references.bib` - bibliography copied from the original package, with additional draft entries for Fujiang Ji-related papers that must be checked before submission.
- `figures/draft/` - staged existing and placeholder figures.
- `tables/ecospectra_proof_of_concept_performance.csv` - early EcoSpectra proof-of-concept metrics.
- `archive/original_package/` - unmodified contents of `HS_perspective_v3.zip`.
- `target/` - target-specific presubmission pitch drafts.
