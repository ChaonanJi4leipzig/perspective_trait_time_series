# Functional ecosystem monitoring Perspective manuscript

This repository is an Overleaf-ready LaTeX project for the Perspective manuscript:

**From greenness to function in ecosystem monitoring**

The manuscript is intended as an opening Perspective for an MSCA research programme on continuous ecosystem trait monitoring. The manuscript should not present the internal project name as if it were a recognized community initiative. It should also not read as a literature review or as a full research article. The current positioning is:

- sparse imaging spectroscopy provides trait anchors;
- dense multispectral archives provide temporal support;
- the target output is a set of uncertainty-aware continuous functional observables;
- a European forest testbed enters as an early proof-of-concept, not as a final benchmark.

## Main files

- `main.tex` - rewritten Perspective draft.
- `references.bib` - bibliography copied from the original package, with additional draft entries for Fujiang Ji-related papers that must be checked before submission.
- `figures/draft/` - staged original figures and earlier proof-of-concept drafts.
- `figures/generated/` - reproducible manuscript figures generated by `scripts/make_perspective_figures.py` in PDF, SVG, EPS, JPG and PNG formats.
- `scripts/make_perspective_figures.py` - Python script for Figure 2, Figure 3, Figure 4 and Figure 5, refactored toward the local Nature-style rules.
- `tables/proof_of_concept_performance.csv` - early proof-of-concept metrics.
- `archive/original_package/` - unmodified contents of `HS_perspective_v3.zip`.
- `target/` - target-specific presubmission pitch drafts.
- `cover_letters/NREE_presubmission_inquiry.md` - more formal NREE inquiry draft.
- `inquiry/NREE_presubmission_inquiry.tex` - Overleaf-ready LaTeX presubmission inquiry package with optional references and figure previews.
- `inquiry/NREE_proposal_synopsis.tex` - NREE-style proposal synopsis with abstract, outline, key references and author affiliations.
- `AUTHOR_NOTES.md` - current author block and affiliation details that need confirmation.
